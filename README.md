# Конструктор план-графиков размещения облигаций

Веб-приложение на **PHP 5.6+** без внешних зависимостей: в браузере собирается
план-график (дорожная карта) сделки, затем выгружается в **XLSX** в дизайне
дорожной карты ГК Сервис-Телеком. Содержимое типового плана взято из шаблона
«План-график FINAL» (53 мероприятия, 17 недель).

## Возможности

- Разделы и мероприятия: название, ответственный, комментарий, один или
  несколько периодов у мероприятия.
- Три типа периодов: **мероприятие** (голубая полоса), **ключевое событие**
  (зелёная ячейка), **ориентировочно** (штриховка).
- Две шкалы: **дни** (даты в шапке, повёрнутые на 90°, выходные и праздники
  подсвечены) и **недели** (номера недель, как в шаблоне).
- Нумерация в каждом разделе с 1 или сквозная; столбец «Комментарий» по желанию.
- Сдвиг всех дат на N дней (с пропуском выходных), перенос плана на новую дату начала.
- Пресеты: типовой план из шаблона и пример ГК Сервис-Телеком.
- Сохранение планов на сервере (каталог `data/`), импорт/экспорт JSON.
- Предпросмотр гантта в браузере в тех же цветах, что и в файле.
- Выгрузка XLSX: шрифт Arial Narrow 9, шапка `#0070C0`, разделы `#DDEBF7`,
  полосы `#BDD7EE`, вехи `#00B050`, границы `#BFBFBF`, закрепление шапки,
  сетка выключена, печать на A3 альбомно по ширине листа, повтор шапки на
  каждой странице, формулы `=D1+1` в шапке дат (как в оригинале).

## Требования

- PHP 5.6 или новее (проверено также на PHP 8.4), расширение **zip**
  (`ZipArchive`), желательно **mbstring**.
- Каталог `data/` должен быть доступен на запись веб-серверу.
- Любой веб-сервер (Apache, nginx + php-fpm) или встроенный сервер PHP.

## Запуск

```bash
php -S 0.0.0.0:8080 -t /путь/к/проекту
```

Откройте `http://localhost:8080/` — загрузите пресет, отредактируйте и нажмите
«Скачать XLSX».

Выгрузка из командной строки (JSON с датами или пресет со смещениями):

```bash
php bin/export-cli.php presets/service-telecom.json out.xlsx
php bin/export-cli.php presets/template-bond-program.json out.xlsx --start=2026-10-05
```

## Структура

| Файл | Назначение |
|------|------------|
| `index.php` | интерфейс конструктора |
| `assets/app.js`, `assets/style.css` | клиентская логика и оформление |
| `export.php` | формирование XLSX (`?validate=1` — только проверка) |
| `api.php` | пресеты, сохранение/загрузка/удаление планов |
| `lib/PlanSchedule.php` | нормализация плана и построение листа |
| `lib/XlsxWriter.php` | минимальный писатель XLSX (стили, объединения, печать) |
| `presets/*.json` | пресеты (сроки заданы смещением в днях от даты начала) |
| `bin/export-cli.php` | выгрузка из командной строки |
| `data/` | сохранённые планы (не попадают в git) |

## Формат плана (JSON)

```json
{
  "name": "План-график АО Пример",
  "issuer": "АО Пример",
  "scale": "day",
  "startDate": "2026-10-05",
  "endDate": null,
  "numbering": "section",
  "showComments": true,
  "holidays": ["2026-11-04"],
  "sections": [
    {
      "title": "Договорная база",
      "tasks": [
        {
          "name": "Подписание Соглашения об организации выпуска",
          "responsible": "Эмитент, Организаторы",
          "comment": "",
          "periods": [
            { "type": "bar", "start": "2026-10-05", "end": "2026-10-16" },
            { "type": "milestone", "start": "2026-10-19", "end": "2026-10-19" }
          ]
        }
      ]
    }
  ]
}
```

`start`/`end` могут быть датами `YYYY-MM-DD`, `ДД.ММ.ГГГГ` или целым смещением
в днях от `startDate` (так устроены пресеты). Если `endDate` не задан, шкала
заканчивается в воскресенье недели последнего мероприятия.
